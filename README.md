## Como executar o projeto

Para executar a aplicação, siga os passos abaixo:

1. Abra a solução do projeto no **Visual Studio**.
2. No **Gerenciador de Soluções**, localize o projeto `vendinha-backend.Desktop`.
3. Clique com o botão direito sobre o projeto e selecione **Definir como Projeto de Inicialização**.
4. Certifique-se de que o projeto `vendinha-backend.Desktop.csproj` esteja selecionado como projeto de inicialização.
5. Após configurar, execute o projeto.

A aplicação será iniciada após a compilação do projeto.
